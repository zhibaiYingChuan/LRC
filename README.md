# LRC · 忆（Loong Recall）

**一个装在自己电脑上的「记忆库 + 代码搜索」，让你的 AI 工具真的记住你。**

[![License: 外壳与前端](https://img.shields.io/badge/%E5%A4%96%E5%A3%B3%E4%B8%8E%E5%89%8D%E7%AB%AF-Apache%202.0-blue.svg)](LICENSE_CODE)
[![License: 核心引擎](https://img.shields.io/badge/%E6%A0%B8%E5%BF%83%E5%BC%95%E6%93%8E-%E4%B8%93%E6%9C%89%E8%AE%B8%E5%8F%AF-red.svg)](LICENSE)

LRC 把你说过的话、做过的决定、写过的代码存成本地记忆。下次你（或你的 AI）问起时，
它能把相关的那几条翻出来，并告诉你"为什么是这几条"。

---

## 它解决什么问题

- **换个会话就忘**：昨天定好的方案，今天要重新讲一遍。
- **找不到旧代码**：只记得"我好像写过类似的东西"，不知道在哪个项目。
- **知识太散**：笔记、聊天记录、代码注释里各有一点，拼不起来。

AI 本身不会跨会话记住这些；LRC 就是给它补上这块记忆。

## 30 秒上手

**使用 LRC 只有一种方式：下载安装包。**

1. 到 [v0.9.15 Releases](https://github.com/zhibaiYingChuan/LRC/releases/tag/v0.9.15) 下载对应平台的**桌面安装包**：
   - Windows：`lrc-desktop-v0.9.15-windows-x86_64-setup.exe`
   - macOS：`lrc-desktop-v0.9.15-macos-arm64.dmg`
   - Linux：`lrc-desktop-v0.9.15-linux-amd64.deb` 或 `lrc-desktop-v0.9.15-linux-x86_64.AppImage`
2. 双击安装并打开，按向导选一个项目目录。
3. 首次会自动下载**本地语义模型**（约 100~400MB，可走国内镜像），下载完就能用。

> Release 里以 `lrc-v0.9.15-...exe` 命名的文件是**命令行工具**，不是安装包，双击装不上。

## 它能做什么

| 场景 | 你会看到什么 |
|---|---|
| **记住偏好与决定** | "以后都用 pnpm"、"这个项目不上 PostgreSQL" —— 下次直接生效，不用再说一遍 |
| **找回旧代码** | 问"我写过限流吗"，它会把相关文件、当时的原因一起翻出来 |
| **自动关联** | 一条记忆能牵出同一次工作里的其他记忆（同一小时、同一文件、同一件事） |
| **给出理由** | 每条结果都带"为什么推送它"，而不是一个黑箱分数 |

## 它怎么工作（尽量说人话）

```
你说的话 / 你写的代码
      │  写入时：在本机编码成向量 + 关键词特征（不联网）
      ▼
   本地记忆库
      │  检索时：两条路一起走
      │    · 快路：按关键词找（快、精确）
      │    · 深路：按语义找（能理解"晚饭"≈"吃什么"）
      ▼
   融合排序 → 联想补全 → 输出结果 + 理由
```

- 所有编码与检索**都在你自己的电脑上**完成，不上传。
- 检索是**只读**的：不会因为查一下就改写你的记忆文件。

## 接入 AI 工具（MCP）

桌面端会**自动**把配置写进 Claude Code / Cursor / Trae 等工具，装完重启 IDE 即可。

如果你用的是常驻端口模式，手动配置是这样：

```json
{
  "mcpServers": {
    "lrc-memory": {
      "type": "http",
      "url": "http://127.0.0.1:3099/mcp"
    }
  }
}
```

> LRC 依赖本机资源（本地模型、本地记忆库、本机代码索引），**不适合部署到远程服务器**。
> 在 ModelScope 等平台登记时，托管类型请选「仅本地可用」。

## 模型与 LLM（都是可选项）

**语义模型**（本地运行，决定"能不能听懂近义说法"）：

| 模型 | 维度 | 体积 | 适合 |
|---|---|---|---|
| `BAAI/bge-small-zh`（默认） | 512 | ~100MB | 中文日常使用 |
| `sentence-transformers/all-MiniLM-L6-v2` | 384 | ~80MB | 英文环境 |
| `BAAI/bge-base-zh` | 768 | ~400MB | 中文高精度 |
| `multilingual-e5-small` | 384 | ~120MB | 多语言混用 |

**LLM**（可选，只用来"写摘要 / 理解提问"）：

- 不配 LLM 也能正常用，只是摘要由本地规则生成。
- 配置后，**只有**查询文本和需要总结的那几条记忆会发给你指定的 LLM；向量始终本地算。
- 支持 OpenAI 兼容接口与本地 Ollama。

## 数据与隐私

- **数据位置**：`~/.loong-recall/`（记忆库、模型、联想记录都在这里）。
- **不上传**：没有遥测、没有埋点；代码索引只驻留内存，不落盘。
- **备份**：直接复制整个 `~/.loong-recall/` 目录即可；换机器时复制回去就恢复。
- **清理**：桌面端设置里可以按项目删除记忆，或直接删目录（会连模型一起删）。

## 最近更新（v0.9.15）

一句话：**检索快了一大截，存储也不再出"假成功""删了又活"这类问题。**

### 更新了什么（新能力）

- **记忆有了"寿命"管理**：可以标记「已被新版本取代」或「被抑制」，检索时不再优先返回过时的那条。
  新增接口 `POST /v1/memories/lifecycle` 供查询与修改。
- **默认全部关闭**：寿命相关的行为（命中记录、按时间衰减）都要显式开开关；不配置时与上一版完全一致。

### 修复了什么（Bug）

- **删掉的记忆重启后又回来了**：清空删除日志失败时会留下"作废标记"，旧记录不再被重放。
- **结晶（记忆融合）没写进去却提示成功**：现在落盘失败会直接报错，不再"成功但写入 0 条"。
- **同一条记忆删两次报 404**：现在删除是幂等的，重复删除也返回成功。
- **检索变慢（本次最大的问题）**：同一条查询由 10.5~12.6 秒降到 **4.1~5.3 秒**；关联推荐由 3.8~4.1 秒降到 **0.14~0.42 秒**。
- **首次打开页面偶发一直转圈**：首屏请求加了 35 秒超时兜底。

### 增强了什么（体验与性能）

- **检索更快**：同一条记忆不再被反复复制；打分从"每个词各扫一遍全文"改成"扫一遍就够"；关联推荐从"每次翻全库"改成"查索引"。
- **结果没有变化**：与上一版逐条 A/B 比对，5 组查询的返回集合与排序位置**完全一致**。
- **后台管理页不再要求登录**；记忆列表上限提到 2000 条；列表刷新不再卡顿。

> 更早版本（0.9.14 及以前）的完整变更见 [CHANGELOG.md](CHANGELOG.md)。

## 常见问题

**1. 模型下载很慢或失败？**
桌面端默认走国内镜像（`hf-mirror.com`）；也可以手动下载模型后放进 `~/.loong-recall/models/`。

**2. 端口 3099 被占用？**
关掉占用进程，或改端口后同步修改 MCP 配置里的 `url`。开发实例端口约定见 CHANGELOG 历史条目。

**3. 记忆会自己变少吗？**
默认不会：检索是只读的。只有你主动删除、或开启"按时间衰减"（默认关闭）才会变化。

**4. 我的代码会被上传吗？**
不会。代码索引在内存里，检索与向量化都在本机完成；只有你自己配置了 LLM，才会把**查询与待摘要的记忆文本**发给该 LLM。

**5. 为什么以前能自己编译，现在不行了？**
自 v0.9.15 起，核心检索引擎源码不再公开（见下节）。公开仓库只保留外壳、前端与文档，
缺少核心源码无法编译，所以只能通过安装包使用。
