用户文档

欢迎使用 LRC（Loong Recall）—— 本地优先的 AI 工具记忆系统。本页面整合了快速上手、配置指南、常见问题与 API 参考，帮助你快速掌握 LRC 的全部功能。

一、快速上手

1.1 安装与首次启动

  1. 下载 LRC Desktop 安装包（.msi 或 .exe）并完成安装。
  2. 启动后进入配置向导，LRC 会自动扫描已安装的 AI 工具（如 Trae、Cursor、VS Code 等）。
  3. 勾选需要配置的工具，选择要索引的项目文件夹。
  4. （可选）配置 LLM API Key 以启用自然语言搜索；不配置也能使用基础搜索功能。
  5. 点击"完成配置"，LRC 将自动启动后台服务并配置 MCP 连接。

1.2 两条配置路径

完整配置（约 30 秒）

检测 AI 工具 + 选项目 → 配置 LLM（可选）→ 自动配置 MCP 并启动。推荐首次使用。

快速上手（约 10 秒）

跳过检测 → 直接选项目文件夹 → 自动配置 MCP 并启动。老手推荐。

1.3 让 AI 记住与回忆

  • 记住信息：在 AI 工具对话中输入 "帮我记住：这个项目使用 React + TypeScript"，AI 会自动调用 LRC 的 remember 工具存储记忆。
  • 回忆信息：在另一个对话中输入 "我之前记录的项目技术栈是什么？"，AI 会调用 LRC 的 recall 工具检索记忆。
  • 更新记忆：直接让 AI 记住新信息，LRC 会自动管理记忆的版本与去重。

1.4 桌面端状态栏说明

  • ● 运行中：服务正常，AI 工具可使用记忆功能。
  • ● 启动中：服务正在启动，请稍候。
  • ● 已停止 / 不可达：点击状态文字（桌面端）或文字本身（仪表盘右下角）可弹出启动服务弹窗。
  • 数据目录：右下角显示的路径可点击直接打开文件夹（仅桌面端）。
二、配置指南

2.1 LLM 配置（可选）

配置 LLM 可启用自然语言搜索代码功能。LRC 支持以下国产模型：

提供商推荐场景获取 Key
DeepSeek代码能力极强，性价比之王获取 →
通义千问阿里云出品，中文理解出色获取 →
智谱 GLM清华系，GLM 系列模型获取 →
MiniMax / 豆包 / 阶跃 / 百川国产多模型可选设置面板中查看
自定义 API任何兼容 OpenAI 协议的 API 地址—

安全说明：API Key 使用 AES-256-GCM 加密存储在本地，绝不上传任何服务器。

2.2 本地语义模型（内置，无需配置）

LRC 内置本地小模型用于代码语义搜索，无需任何配置即可使用。默认根据系统语言自动选择：

  • 中文环境：BAAI/bge-small-zh（512 维，约 95MB，中文 SOTA）
  • 其他语言：sentence-transformers/all-MiniLM-L6-v2（384 维，约 80MB，多语言轻量）

模型首次启动时从国内镜像（HfMirror / ModelScope）下载，支持断点续传和指数退避重试。下载失败时自动回退到 TF-IDF 统计算法，不影响基础功能。可通过环境变量 LRC_LUOSHU_MODEL_ID 切换其他模型。

2.3 MCP 配置

LRC 通过 HTTP 模式自动为 AI 工具配置 MCP 连接。配置完成后无需手动操作。

  • 支持的 IDE：Trae、Trae CN、Cursor、VS Code、CodeBuddy 等 36+ 工具。
  • 配置位置：用户级配置（~/.trae/mcp.json 等），对所有项目生效。
  • 部分 IDE 限制：Cursor、VS Code 需在项目目录下手动创建 mcp.json，LRC 无法自动写入项目级配置。
  • 规则文件：LRC 会自动为已安装的 AI 工具写入全局规则文件（如 ~/.trae-cn/user_rules/rules.md），让 AI 知道如何使用记忆工具。

2.4 数据存储位置

LRC 的数据完全存储在本地，路径如下：

  • 项目模式：~/.loong-recall/projects/{项目指纹}/data/
  • 全局模式：~/.loong-recall/global/data/
  • 旧版兼容模式：<项目目录>/.loong-recall/data/
  • Windows：%USERPROFILE%\.loong-recall\
  • Linux / macOS：~/.loong-recall/

点击仪表盘右下角的"数据目录"路径可直接打开该文件夹。

2.5 端口自适应

LRC 默认使用 3099 端口。若端口被占用，会自动尝试 3100-3198 范围内的端口，无需手动配置。

三、常见问题（FAQ）
Q1：为什么 AI 工具提示"无法连接到 LRC 服务"？

可能原因：

  1. LRC 后台服务未启动 → 点击仪表盘左下角"已停止 / 不可达"启动服务。
  2. 端口被占用 → LRC 会自动尝试其他端口，但 MCP 配置可能仍指向旧端口，请重新配置。
  3. 防火墙拦截 → 检查防火墙是否允许 127.0.0.1:3099 的本地通信。
Q2：API Key 是否安全？会被上传吗？

API Key 使用 AES-256-GCM 加密存储在本地配置文件中，绝不会上传到任何服务器。LRC 是本地优先的应用，所有数据完全存储在你的电脑上。

Q3：不配置 LLM 能用吗？

可以。不配置 LLM 也能使用基础的代码搜索和记忆存储功能。配置 LLM 仅用于增强自然语言查询的翻译能力（将"这个项目的认证逻辑在哪里"翻译为精确的检索向量）。

Q4：切换项目后，之前的记忆还在吗？

在。LRC 通过项目指纹为每个项目独立存储记忆。切换到新项目时，新项目有独立的记忆空间；切回原项目时，原项目的记忆完整保留。

Q5：LRC 支持哪些 AI 工具？

支持 36+ 工具，包括：

  • IDE 类：Trae、Trae CN、Cursor、VS Code、JetBrains 系列、Sublime Text、Vim/Neovim、Zed
  • CLI 类：Claude Code CLI、Qwen Code、Aider、Continue.dev、Cline
  • Agent 类：Windsurf、Cody Sourcegraph、Tabnine、Codeium、Replit AI、DeepSeek Coder

对于不支持 MCP 的工具（如 Vim），LRC 会提供手动配置指南。

Q6：如何备份/迁移记忆数据？

两种方式：

  1. UI 方式：在仪表盘"设置"标签页点击"备份记忆"按钮，会下载 JSON 备份文件。
  2. 命令行：code-memory-server --export backup.json 和 code-memory-server --import backup.json

也可以直接复制 ~/.loong-recall/ 目录到新机器。

Q7：服务启动后 AI 工具仍然连不上怎么办？

排查步骤：

  1. 确认仪表盘左下角显示"运行中"。
  2. 在 AI 工具中检查 MCP 服务器列表是否包含 LRC。
  3. 重启 AI 工具（部分 IDE 修改 MCP 配置后需要重启）。
  4. 查看 LRC Desktop 设置面板中的"MCP 配置"是否指向正确端口。
  5. 如仍无法解决，点击"重新启动后台服务"按钮重启 sidecar。
Q8：本地语义模型如何下载？是否会联网？

LRC 内置本地小模型（语义嵌入模型），无需用户配置。中文环境默认使用 BAAI/bge-small-zh（约 95MB），其他语言使用 sentence-transformers/all-MiniLM-L6-v2（约 80MB）。

模型首次启动时从国内镜像（HfMirror / ModelScope）下载，支持断点续传和指数退避重试（2s/4s/8s）。下载失败时自动回退到 TF-IDF 统计算法，不影响基础功能。可通过环境变量 LRC_LUOSHU_MODEL_ID 切换其他模型。

模型下载仅在首次使用时发生，之后完全离线运行，数据不会离开你的电脑。

四、使用技巧

4.1 高效记忆的写法

  • 具体而非抽象："认证模块位于 src/auth/jwt.rs，核心函数是 issue_token()" 优于 "项目有认证功能"。
  • 包含文件路径：让 AI 在后续会话中能精确定位。
  • 记录决策原因："选择 PostgreSQL 因为需要事务支持" 比 "使用 PostgreSQL" 更有价值。
  • 分批记录：将复杂信息拆成多条小记忆，LRC 会自动关联。

4.2 自然语言搜索技巧

  • 问"在哪里"："用户认证的逻辑在哪里？"
  • 问"是什么"："这个项目的数据库 schema 是什么？"
  • 问"为什么"："为什么用 JWT 而不是 session？"
  • 问"如何做"："如何添加一个新的 API 端点？"

4.3 系统托盘管理

LRC 设计为后台静默运行，关闭主窗口后可通过系统托盘图标（任务栏右下角）右键菜单管理：

  • 双击托盘图标 → 打开仪表盘
  • 右键 → 显示主窗口 / 退出 LRC
  • 托盘图标颜色反映服务状态（绿色=运行中，黄色=启动中，红色=未运行）
