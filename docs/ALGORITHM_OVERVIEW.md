# 记忆架构概述

**安全版本 —— 仅描述高层设计思想，不披露核心算法实现细节。**

---

## 设计哲学

Loong Recall 的记忆系统基于一个核心洞察：**记忆不应该只是"存下来"，而应该像人类记忆一样自动演化、抽象、分层**。

传统记忆系统将每条记忆视为平等的向量，依赖相似度排序来决定返回哪些。这种方式在记忆量增长时会遇到两个根本性问题：

1. **检索效率崩溃**：每次查询都要扫描全库计算相似度，O(N log N) 的复杂度在百万级规模下不可接受
2. **知识扁平化**：所有记忆地位平等，无法区分"重要的旧知识"和"新鲜的噪音"

Loong Recall 的解决方案是将记忆从**向量空间**迁移到**几何坐标空间**。

---

## 核心概念

### 1. 几何坐标空间

每条记忆被映射到一个低维整数坐标空间，而非高维浮点向量。这个坐标空间具有明确的几何结构：

- **相近位置的记忆语义相近**，无需每次计算相似度
- **检索从 O(N log N) 降至 O(roi_ratio × N)**，因为只需检查坐标空间中的一个局部区域
- **记忆之间的关系由几何距离决定**，而非浮点运算

### 2. 记忆深度与拓扑演化

记忆不仅仅是"一条文本"，它具有**深度**属性（0~5 层），代表从原始感知到抽象知识的演化过程：

| 深度 | 名称 | 说明 | 示例 |
|---|---|---|---|
| 0 | 感觉记忆 | 原始输入，被动记录 | "用户说要用 pnpm" |
| 1 | 情节记忆 | 事件片段，关联上下文 | "用户偏好 pnpm 包管理" |
| 2 | 语义记忆 | 概念抽象，提炼关键信息 | "项目构建工具选型" |
| 3 | 程序记忆 | 通用模式，可复用 | "新项目初始化流程" |
| 4+ | 架构记忆 | 系统级知识，永久存储 | "微服务架构设计原则" |

深度不是人工标注的，而是系统通过**递归合成**自动演化的：

```
感觉记忆 (depth 0)
    ↓ 同类记忆达到一定条件 → 自动融合
情节记忆 (depth 1)
    ↓ 继续融合
语义记忆 (depth 2)
    ↓ 继续融合
程序记忆 (depth 3)
    ↓ 继续融合
架构记忆 (depth 4+)
```

### 3. 区域检索（ROI 剪枝）

查询时，系统不会扫描全库，而是：

1. 确定查询文本在几何坐标空间中的位置
2. 仅在一个**可配置的感兴趣区域**内遍历候选记忆
3. 区域内按几何距离排序返回 Top-K

这个设计带来了三个关键优势：

- **检索延迟可控**：无论记忆总量多大，实际检索只涉及局部区域
- **深度越大越优先**：深度较大的记忆天然位于坐标空间中心附近，检索时总是优先被命中
- **噪声自动边缘化**：不相关或低质量的记忆自然分布在坐标空间外围，不会干扰检索

### 4. 抗遗忘机制

记忆的持久性由其几何位置决定：

- **中心区域的记忆**：深度大、重要性高，半衰期趋近无限——即永久存储
- **中间区域的记忆**：随访问频率和重要性自然衰减
- **边缘区域的记忆**：噪声和临时信息，自然过期后被归档

这种设计比传统的 TTL（过期时间）机制更智能：它不需要用户手动设置每条记忆的过期时间，系统根据记忆的结构属性自动决定保留策略。

### 5. 可逆组合（RecursiveUnfold）

大多数记忆系统只做"聚合"——将多条记忆合并为一条。但一旦合并，原始信息就永久丢失了。

Loong Recall 支持**可逆组合**：
- `RecursiveCompose`：将多条低层记忆合成为一条高层记忆
- `RecursiveUnfold`：将合成后的记忆拆解回原始子步骤

这意味着你可以：
- 查看一条高层决策是由哪些具体事件推导出来的
- 在需要时回溯到原始上下文
- 修正错误的合成结果而不丢失原始数据

## 与传统方案的对比

| 维度 | 传统向量检索 / RAG | Loong Recall |
|---|---|---|
| **记忆表示** | 高维浮点向量（768~4096 维） | 低维整数坐标 |
| **检索方式** | 全库 ANN → 相似度排序 | 几何定位 → ROI 遍历 |
| **检索复杂度** | O(N log N) | O(roi_ratio × N) |
| **记忆组织** | 扁平向量空间，无结构 | 分层几何空间，有方向性 |
| **知识抽象** | 不支持 | 递归合成自动演化 |
| **长期记忆** | TTL 过期删除 | 中心半衰期无限，外围自然衰减 |
| **可回溯性** | 不支持 | Unfold 拆解到子步骤 |
| **抗噪声** | 依赖阈值过滤 | 几何边缘化 |
