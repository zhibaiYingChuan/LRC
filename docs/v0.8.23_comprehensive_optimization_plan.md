### 2.1 P0 — 阻断级（必须立即修复）

| 编号 | 问题 | 来源 | 域 | 描述 |

| P0-01 | **release.yml 权限过于宽松**（contents: write） | 发布合规 | 安全 | 所有 tag 推送自动获得写入权限，缺少最小权限原则 |

| P0-09 | **首次使用引导缺失** | 产品经理审计 | 用户体验 | 新用户首次打开桌面端无引导流程，上手门槛高 |

## 4. 关键决策

### 4.1 必须立即修复（S1 红线）

| 决策 | 理由 | 后果若推迟 |
|------|------|-----------|
| **Actions 固定 SHA** | 供应链安全是底线，不可妥协 | 第三方 Action 被投毒可导致 CI 执行恶意代码 |

| **harden-runner 配置** | CI 环境网络/文件系统不可控 | 泄露 GitHub token 可导致仓库被完全控制 |
| **E4 代理检测 + D6 Enter 拦截** | HCSE 审计唯一 2 项 FAIL | 93.5% → 100% 不变式通过率的最后缺口 |
| **关键路径 unwrap 降级（Top 30）** | 生产环境 panic 直接导致服务中断 | 用户体验差，可能丢失记忆数据 |
