## 2. RICE 优先级评分

### 2.1 RICE 评分框架说明

| 维度 | 定义 | 分值范围 |
|------|------|---------|
| **Reach（影响范围）** | 该问题影响多少用户/场景 | 1-5 |
| **Impact（影响程度）** | 对用户体验/系统稳定性的影响深度 | 1-5 |
| **Confidence（置信度）** | 我们对问题存在和修复方案的确定程度 | 1-5（50%=1, 80%=3, 100%=5） |
| **Effort（投入工时）** | 修复所需工时（反向计分，工时越低越好） | 1-5（1=1h, 2=2h, 3=4h, 4=8h, 5=16h+） |

**RICE 分数 = (Reach × Impact × Confidence) / Effort**

3. 或：将检测逻辑统一到 `agent_detector.rs`，`server.rs` 通过 HTTP API 获取检测结果

**注意**：此修复涉及架构调整，**建议延后到 v0.8.26**，v0.8.25 仅做日志一致性对齐。
