Loong Recall (L-RC / 忆) — AI 编程助手的记忆与检索插件

用法: code-memory-server [选项]

搜索模式（三层优先级，第1位→第2位→最后）：
  第1位 — Fast Match（默认）: 零网络、零下载、秒启动，关键词匹配
  第2位 — LLM API Key: 交互式引导配置 API，用 LLM 翻译自然语言查询
  最后   — Smart Match: 用户确认后才从国内镜像下载，绝不访问外网

选项:
  --src-dir <路径>    要索引的项目源码目录 [默认: 当前目录]
  --host <地址>       HTTP 绑定地址 [默认: 127.0.0.1]
  --port <端口>       HTTP 绑定端口 [默认: 3099]
  --stdio             使用 stdio 传输模式（IDE 标准 MCP，推荐）
  --global            记忆跨项目共享 (~/.loong-recall/global/data/)
  --db-path <路径>    自定义记忆数据存储路径（优先级最高）
  --data-dir <路径>   自定义数据根目录（V2 统一数据目录）
  --llm-api <配置>    配置 LLM 查询翻译 (Tier 2)，格式见下方说明
  --proxy <代理地址>    HTTP/HTTPS 代理（如 http://127.0.0.1:7890）
  --mode <模式>        搜索模式: fast(默认/Tier1) | smart(Tier3,用户确认+国内镜像下载)
  --dashboard          启动桌面仪表盘模式（自动打开浏览器，含完整交互引导）
  --daemon             后台守护模式（无控制台运行，供桌面端agent使用）
  --tray               启用系统托盘图标（Windows 原生，右键菜单操作）
  --multi-window <N>   多窗口上限 (1~20, 默认 1)，允许同项目多窗口运行
  --install-ide <IDE>  自动配置 IDE/工具的 MCP 连接
                       IDE: trae, trae-cn, cursor, vscode, windsurf, kiro
                       CLI/桌面: gemini, comate, roo, cline, cloudbase
                       多工具用逗号分隔: --install-ide trae,cursor
  --benchmark         运行三层基准测试（人类可读输出）
  --benchmark-json    运行三层基准测试（JSON 格式，供 CI/CD 或仪表盘使用）
  --export <路径>     导出记忆数据到 JSON 文件（备份）
  --import <路径>     从 JSON 文件导入记忆数据（恢复）
  --help, -h          显示此帮助信息

模型管理子命令（v0.6.0 新增）：
  model list                       列出已下载的模型
  model download <model_id>        下载模型（需 ml feature）
  model use <model_id>             设置默认模型（输出环境变量配置指引）
  model remove <model_id>          删除模型文件（需确认）

  示例:
    code-memory-server model list
    code-memory-server model download BAAI/bge-small-zh
    code-memory-server model use BAAI/bge-small-zh
    code-memory-server model remove BAAI/bge-small-zh

举个栗子:
  # Tier 1 — 默认快速模式（零网络、零下载、秒启动）
  code-memory-server --src-dir ./src --port 3099

  # Tier 1 — 一键安装到 Trae IDE（自动配置 MCP）
  code-memory-server --install-ide trae

  # Tier 2 — 配置 LLM 查询翻译，用自然语言搜索代码
  code-memory-server --src-dir ./src --stdio --llm-api openai:sk-xxx:gpt-4o-mini

  # Tier 2 — 使用本地 Ollama 模型（零成本，无需下载）
  code-memory-server --src-dir ./src --stdio --llm-api ollama:localhost:llama3

  # Tier 3 — 语义搜索（用户确认后才从 hf-mirror.com 国内镜像下载，约 1-3 分钟）
  code-memory-server --mode smart

  # 全局记忆，跨项目共享偏好和知识
  code-memory-server --global --stdio

  # 桌面端agent — 后台守护进程 + 系统托盘（供各种桌面agent调用）
  code-memory-server --daemon --tray --src-dir ./src

  # 双击 exe 或 --dashboard 打开可视化仪表盘（含完整交互引导）
  code-memory-server --dashboard

  # 多窗口模式：允许同项目最多 3 个窗口同时运行 LRC
  code-memory-server --src-dir ./src --multi-window 3 --stdio

  code-memory-server --db-path D:/my-data --stdio

  # V2: 导出/导入记忆数据（备份与恢复）
  code-memory-server --export ~/backup/lrc-2026-06-15.json --src-dir ./src
  code-memory-server --import ~/backup/lrc-2026-06-15.json --src-dir ./src

LLM API 配置格式:
  OpenAI:   openai:<sk-key>:<model-name>:<api-base-url>
  Ollama:   ollama:<host>:<model-name>

启动后在 IDE 中配置 MCP 连接，AI 助手即可使用。
访问 http://localhost:3099/dashboard 查看可视化记忆管理仪表盘。
