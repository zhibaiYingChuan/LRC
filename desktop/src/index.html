LRC Desktop

本地优先的 AI 工具记忆系统 — 检测你的 AI 工具并配置 MCP 连接

🧠
LRC 是什么？ LRC 是一个本地代码记忆系统，它能让你的 AI 编程工具（如 Trae、Cursor）记住你的代码上下文，实现跨会话的智能代码搜索和理解。
⚡ 两条路径可选：
① 完整配置：检测 AI 工具 + 选项目 → 配置 LLM（可选）→ 自动配置 MCP 并启动（约 30 秒，推荐首次使用）
② 快速上手：跳过检测 → 直接选项目文件夹 → 自动配置 MCP 并启动（约 10 秒，老手推荐）
💡 配置只需做一次，以后打开直接进入「已就绪」状态。只有切换项目时才需要重新配置。
⚠️ 注意：部分 IDE（如 Cursor、VS Code）需在项目目录下手动创建 mcp.json 文件，LRC 无法自动写入项目级配置。

🔌 配置 AI 工具连接 LRC

LRC 通过 MCP 协议（HTTP 模式）与各种 AI 工具通信。选择你的工具查看配置方法。
注意：只有拥有全局配置路径的 AI 工具（如 Trae、Trae CN、Windsurf、Claude Desktop、CodeBuddy、Gemini CLI 等）能被自动配置。
Cursor、VS Code 等 IDE 需要你在项目目录下手动创建 mcp.json 文件（使用 HTTP URL 格式）。
前提条件：必须先启动 LRC Desktop 应用，AI 工具才能通过 HTTP 端点连接。

IDE 类 AI 工具配置

🔥 Trae

LRC 可自动配置 Trae 的 MCP 连接（HTTP 模式）。如需手动配置，在 Trae 设置 → MCP → 添加 → 手动添加：

{
  "mcpServers": {
    "lrc-memory": {
      "url": "http://127.0.0.1:3099/mcp"
    }
  }
}

⚠️ 需先启动 LRC Desktop 应用。端口号请以状态栏显示为准（默认 3099）。

🖥️ Cursor

⚡ Aider

其他 AI 产品配置

🌐 浏览器插件（Agent Browser / Playwright MCP）

通过 HTTP 端点连接（需要 LRC Desktop 在后台运行）：

http://127.0.0.1:3099/mcp

在浏览器插件的 MCP 设置中填入上述 URL。

⚠️ 端口号请以状态栏显示为准。

🔧 自定义集成

LRC 提供标准 MCP 协议接口，任何支持 MCP 的工具都可以连接：

  • HTTP 端点（推荐）: http://127.0.0.1:3099/mcp（需 LRC Desktop 在后台运行）
  • REST API: http://127.0.0.1:3099/v1/*
  • 仪表盘: http://127.0.0.1:3099/dashboard

⚠️ 端口号请以状态栏显示为准。LRC Desktop 使用 HTTP 模式，不支持 stdio 模式。
